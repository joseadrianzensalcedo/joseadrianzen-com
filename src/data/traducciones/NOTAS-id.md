# Notas, indonesio (id)

- "clave alta" / "clave baja": se dejó "high key" / "low key", que es el término que usa la fotografía en Indonesia. Confirmar con hablante nativo.
- "Ingeniería empresarial, UTP": traducido como "Rekayasa bisnis". No hay carrera equivalente exacta, revisar.
- "Mención especial": "Penghargaan Khusus". En festivales indonesios a veces se deja "Special Mention" en inglés.
